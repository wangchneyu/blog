## 三、本轮执行项

### A · 重做 OG 图（分享卡片）

**问题**：`public/og-default.png` 上的文案是 `Full-Stack · AI Agent · Math Modeling`，
与首页「科研是主线」的定位相反。别人在微信 / 飞书 / Twitter 里看到的是「一个全栈工程师」，
点进来却看到「一个做多视图聚类研究的本科生」——两次认知不连续，是这个站目前最贵的浪费。

**做法**：
- 用 HTML 渲染后无头浏览器截图（规避 `next/og` 的中文字体依赖问题，仓库不引入字体文件）
- 尺寸保持 1200×630
- 内容按新的信息层级：姓名 → 学校专业 → 两条主线 → 三枚证据
- 深色底 + 站点同一套极光渐变，与站内视觉连续

**验收**：`/og-default.png` 打开后，不放大也能读出「谁 / 在哪 / 做什么 / 凭什么」。

### B · 一页纸（打印 / 存 PDF）

**问题**：访客（导师、面试官）想留一份，只能截图或手抄。而做独立的 `/resume` 页会让
about 的内容维护两份，早晚不一致。

**做法**：给 `/about` 加打印样式，不新增页面、不复制内容。

- `globals.css` 加全局打印规则：隐藏 header / footer / 装饰光斑；底色强制白、文字强制黑
- `about/page.module.css` 加页面级打印规则：
  - 字号压到 10pt 级、行高收紧，四节压进 2 页内
  - 每个 `article` 禁止跨页断裂（`break-inside: avoid`）
  - 隐藏「返回首页」「查看全部项目」等导航性元素
  - 外链在文字后补出 URL（`::after { content: " (" attr(href) ")" }`），纸质版也能找到
- 页面加一个「打印 / 存为 PDF」按钮，`window.print()`，打印时自身隐藏

**验收**：Chrome 打印预览下 `/about` 不超过 2 页、无深色块、无被截断的条目、无导航残留。

### C · 本轮不做

| 项 | 原因 |
|---|---|
| 头像 / monogram | 没有照片时，字母圆圈本质上是占位符，反而强化「还没做完」的观感。等图到位，10 分钟可加 |
| 动态 OG（按文章标题生成） | 只有 1 篇公开文章，收益远小于成本；且中文字体方案会让仓库多几 MB |
| `/resume` 独立页 | 与 about 内容重合，打印样式已覆盖同一需求 |
| 首页 Now / 时间线 | 需要用户提供「最近在做什么」，否则就是编 |

### 两处与方案不一致的地方

1. **打印时把「关于我」标题也隐藏了**。基础规则最初写的是 `header, footer, nav { display: none }`，
   而 about 页的页头是语义 `<header>`，被一起干掉。改为 `body > header` / `body > footer` 后恢复正常。
   教训：全局打印规则不要用裸标签选择器。

2. **页边距从 15mm 收到 12mm**。首版在 Letter 纸张下溢出到第 2 页；实测可用高度 965px、内容 970px，
   只差 5px。收边距 + 章节间距从 0.7rem 压到 0.58rem 后落到 1 页。
