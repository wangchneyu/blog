这份文档不出现在生产构建里（`draft: true`），它存在的目的是：写完新元素样式后有一个能立刻打开对照的页面，而不是靠猜。

## 表格

默认表格带表头底色、行分隔与斑马纹，外层有滚动容器包裹，窄屏下横滑不会撑破正文。

| 元素 | 语法 | 状态 | 说明 |
| :--- | :---: | ---: | :--- |
| 表格 | `\| a \| b \|` | 已覆盖 | 窄屏横滑 |
| 图片 | `![]()` | 已覆盖 | 支持题注 |
| 任务列表 | `- [ ]` | 已覆盖 | 去掉双符号 |
| 分隔线 | `---` | 已覆盖 | 渐变细线 |

列对齐由 Markdown 语法决定，上表分别为左、中、右、左。宽表用来验证横向滚动：

| 场景 | 输入 | 处理 | 输出 | 耗时 | 备注 |
| :--- | :--- | :--- | :--- | ---: | :--- |
| 首次访问 | 冷启动 | 预渲染 | 静态 HTML | 12ms | 边缘缓存 |
| 二次访问 | 热缓存 | 直接命中 | 静态 HTML | 3ms | — |
| 增量更新 | 提交 | 重建 | 静态 HTML | 40s | 仅变更页 |

## 图片与题注

`title` 属性会被提取为题注，不写 `title` 则只渲染图片。

## 引用

> 中文没有真正的斜体字形，浏览器会用伪斜体倾斜，观感并不好。所以引用块改用左侧竖线加浅底色承担语义。
>
> 这是引用的第二段，用来确认段间距与底部留白是否收敛。

站内链接保持默认行为，例如 [返回所有文章](/blog)。站外链接会带箭头并新开窗口，例如 [Next.js 文档](https://nextjs.org/docs)。

行内代码写作 `const answer = 42`，块级代码如下：

```ts
type Element = "table" | "img" | "figure" | "hr" | "task-list";

export function isExtended(el: Element) {
  return el !== "hr" || true;
}
```
